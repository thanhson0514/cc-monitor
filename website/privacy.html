SummaryTóm tắt

ccmon runs entirely on your computer. It has no account, no analytics and no telemetry, and the ccmon code makes no network requests. It reads files Claude Code already keeps on your machine and writes only its own state — plus, when you ask for it, a status-line wrapper and agent files.

This page explains exactly what the ccmon desktop app and terminal UI read and write, the few situations where something other than ccmon goes online, and what this website collects. It describes the code as published in the repository; since ccmon is open source, you can verify every statement there.

ccmon chạy hoàn toàn trên máy bạn. Không tài khoản, không analytics, không telemetry, và code của ccmon không gửi yêu cầu mạng nào. Nó đọc các file Claude Code vốn đã lưu trên máy và chỉ ghi trạng thái của riêng nó — cùng, khi bạn yêu cầu, lớp bọc status line và file agent.

Trang này giải thích chính xác ứng dụng desktop và giao diện terminal của ccmon đọc và ghi gì, vài trường hợp mà thứ khác ccmon kết nối mạng, và website này thu thập gì. Nội dung mô tả code đã công bố trong repo; vì ccmon là mã nguồn mở, bạn có thể tự kiểm chứng từng điều ở đó.

What ccmon readsccmon đọc gì

  • Transcripts: ~/.claude/projects/**/*.jsonl — sessions, sub-agents, workflow agents. These contain your prompts, the model's answers, tool inputs and outputs, and file contents the agent read or wrote.
  • File backups Claude Code keeps in ~/.claude/file-history/, to show diffs against the file before the session.
  • Capabilities: skills, agents, workflows and plugins under ~/.claude and the project's .claude/; MCP server definitions from ~/.claude.json and .mcp.json. For MCP servers only the name, transport, command and URL are used — environment variables and headers are not read into the UI, and credentials and query strings are stripped from URLs before display.
  • Claude Code's settings.json, to show and (if you opt in) wrap your status-line command.
  • Files the agent referenced, when you open them in the assets panel or file viewer, and background-task output files while a task runs.
  • Git: git show HEAD:<path> runs locally when you compare a file against git HEAD.
  • System information: whether a Claude Code process is still running (to mark sessions open or closed) and memory usage for the status bar.

All of this stays in memory on your machine. Nothing is copied elsewhere, indexed into a database or uploaded.

  • Transcript: ~/.claude/projects/**/*.jsonl — phiên, subagent, agent của workflow. Chúng chứa prompt của bạn, câu trả lời của model, đầu vào và đầu ra của tool, và nội dung file agent đã đọc hoặc ghi.
  • Bản sao lưu file Claude Code giữ trong ~/.claude/file-history/, để hiện diff so với file trước phiên.
  • Capability: skill, agent, workflow và plugin trong ~/.claude và .claude/ của dự án; định nghĩa MCP server từ ~/.claude.json và .mcp.json. Với MCP server chỉ dùng tên, kiểu kết nối, lệnh và URL — biến môi trường và header không được đưa lên giao diện, thông tin đăng nhập và query string bị cắt khỏi URL trước khi hiển thị.
  • settings.json của Claude Code, để hiện và (nếu bạn đồng ý) bọc lệnh status line.
  • File agent đã nhắc tới, khi bạn mở chúng trong panel Quản lý hoặc trình xem file, và file output của tác vụ nền khi tác vụ đang chạy.
  • Git: git show HEAD:<path> chạy cục bộ khi bạn so file với git HEAD.
  • Thông tin hệ thống: tiến trình Claude Code còn chạy không (để đánh dấu phiên đang mở hay đã đóng) và mức dùng bộ nhớ cho thanh trạng thái.

Tất cả chỉ nằm trong bộ nhớ trên máy bạn. Không gì bị sao chép đi nơi khác, đưa vào cơ sở dữ liệu hay tải lên.

ccmon never edits transcripts, skill, plugin or MCP files, and never changes settings.json to switch capabilities off — those are launch flags for sessions run from ccmon.

ccmon không bao giờ sửa transcript, file skill, plugin hay MCP, và không đổi settings.json để tắt capability — việc đó dùng cờ khởi chạy cho session chạy từ ccmon.

NetworkKết nối mạng

The ccmon source contains no code that opens a network connection: no HTTP requests in the Rust core, the Tauri backend or the React frontend, and the frontend loads no remote scripts, fonts or images. (The Tauri framework ships an HTTP client library among its dependencies; ccmon does not use it.) There is no update check and no crash reporting.

Things that can go online, and are not ccmon:

  • Sessions you run from ccmon. The composer starts your own claude binary, which talks to Anthropic (or whichever provider your Claude Code is configured for) exactly as when you run it in a terminal. Your prompts go there under your Claude Code account and its terms — ccmon sees only what Claude Code writes to the local transcript.
  • Your status-line command. The wrapper runs your original command unchanged; if that command uses the network, it still does.
  • The Windows installer. If WebView2 is missing, the setup downloads Microsoft's WebView2 bootstrapper.
  • MCP servers, plugins and hooks are run by Claude Code, not by ccmon.
  • Links you click. A web link clicked in a transcript is handed to your default browser; ccmon does not fetch it itself.

Mã nguồn ccmon không có đoạn code nào mở kết nối mạng: không có yêu cầu HTTP trong lõi Rust, backend Tauri hay frontend React, và frontend không tải script, font hay ảnh từ xa. (Framework Tauri có một thư viện HTTP client trong các phụ thuộc; ccmon không dùng nó.) Không có kiểm tra cập nhật và không có báo cáo lỗi tự động.

Những thứ có thể kết nối mạng, và không phải ccmon:

  • Session bạn chạy từ ccmon. Ô soạn khởi chạy chính lệnh claude của bạn, và nó làm việc với Anthropic (hoặc nhà cung cấp mà Claude Code của bạn cấu hình) y như khi chạy ở terminal. Prompt của bạn đi tới đó theo tài khoản và điều khoản Claude Code của bạn — ccmon chỉ thấy những gì Claude Code ghi vào transcript cục bộ.
  • Lệnh status line của bạn. Lớp bọc chạy nguyên lệnh gốc; nếu lệnh đó dùng mạng thì vẫn dùng.
  • Bộ cài Windows. Nếu máy thiếu WebView2, bộ cài tải WebView2 bootstrapper của Microsoft.
  • MCP server, plugin và hook do Claude Code chạy, không phải ccmon.
  • Liên kết bạn bấm. Liên kết web bấm trong transcript được chuyển cho trình duyệt mặc định; ccmon không tự tải nó.

This websiteWebsite này

  • Hosted on GitHub Pages. GitHub may log technical data such as your IP address when serving the pages; see the GitHub Privacy Statement.

  • Trang chủ hỏi GitHub API công khai (api.github.com) về bản phát hành mới nhất để nút tải trỏ đúng file.
  • Lựa chọn ngôn ngữ được lưu trong bộ nhớ cục bộ của trình duyệt (ccmon-lang). Website không tự đặt cookie và không dùng analytics hay công cụ theo dõi.

When you share something with usKhi bạn chia sẻ với chúng tôi

Issues, pull requests and discussions on GitHub are public. Screenshots and logs of ccmon can show prompts, code, file paths and project names — please remove anything private before posting, and never attach real transcripts. For security issues use the private channel described in the Security policy.

Issue, pull request và thảo luận trên GitHub là công khai. Ảnh chụp và log của ccmon có thể lộ prompt, code, đường dẫn file và tên dự án — hãy xoá mọi thứ riêng tư trước khi đăng, và không bao giờ đính kèm transcript thật. Với vấn đề bảo mật, hãy dùng kênh riêng tư ở trang Chính sách bảo mật.
